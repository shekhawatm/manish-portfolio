# manish-portfolio
Personal portfolio of Manish Shekhawat: hiring, people ops and AI-built HR systems. Built with Next.js, Tailwind and Claude Code.

Live site: ADD THE VERCEL LINK HERE

## What this is

A one-page site that shows how I work: hiring, People Ops, payroll and the tools I build with AI. All numbers are aggregate, and the tool mockups use fake demo data.

## Built with

- Next.js and TypeScript
- Tailwind CSS
- Framer Motion
- Built with Claude Code, hosted on Vercel

## Run it on your computer

1. Install the packages: npm install
2. Start the site: npm run dev
3. Open http://localhost:3000 in your browser

## How to edit the words

All text lives in one file: src/content.ts. Change the words there and the site updates. No design code needs touching.

## Privacy

This site contains no real company data, no names of colleagues or candidates, and no compensation details. A check script runs before each commit to catch anything that should not be there.
